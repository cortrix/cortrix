# Support Playbook

Support agents should answer with enough evidence for a teammate to review the result later.

Every answer should include:

- the direct answer;
- at least one source reference;
- any visible limitation;
- whether the issue needs a human reviewer;
- whether a retry is safe or the request shape should be repaired.

Support agents should not treat a confident answer as final when sources disagree. If an older checklist conflicts with a newer release policy, the conflict should be shown to a reviewer.

The team uses evidence cards for handoff. An evidence card should keep the input, answer, source, trace, and limitation in one place.
